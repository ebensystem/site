EBENSYSTEM V5
==============

Site institucional da Ebensystem Tecnologia LTDA.

Estrutura:
- index.html              -> página inicial
- servicos/index.html     -> serviços
- clientes/index.html     -> modelo de atuação / terceirização técnica
- historia/index.html     -> apresentação da empresa
- contato/index.html      -> formulário de contato
- app.js                  -> menu responsivo
- css/style.css           -> identidade visual e responsividade
- img/logo.png            -> logotipo

Navegação:
- /              -> index.html
- /servicos/     -> servicos/index.html
- /clientes/     -> clientes/index.html
- /historia/     -> historia/index.html
- /contato/      -> contato/index.html

Os links internos foram ajustados para caminhos relativos, incluindo os caminhos
de CSS, JavaScript e imagens nas páginas internas.

O site mantém o endpoint do formulário Google Apps Script presente na versão recebida.
Antes de publicar em produção, confirme que esse endpoint continua ativo e autorizado
a receber as mensagens.
